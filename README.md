# Лабораторная работа 6 «Поиск фильмов» (React + OMDb API)

## Как запустить (Windows)

Нужен Node.js 18 или новее: https://nodejs.org (версия LTS).

Откройте папку проекта в терминале (в VS Code: Терминал → Новый терминал) и выполните:

```
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).


## API-ключ OMDb
OMDb требует бесплатный ключ:
1. Зайдите на https://www.omdbapi.com/apikey.aspx, выберите **FREE! (1,000 daily limit)**, введите email.
2. Активируйте ключ по ссылке из письма (письмо иногда приходит в течение часа).
3. Скопируйте файл `.env.example` в `.env` и впишите ключ:
   ```
   VITE_OMDB_API_KEY=abcd1234
   ```
4. `npm install`, затем `npm run dev`. Если сервер уже был запущен — перезапустите его после создания `.env`.

Можно вписать ключ прямо в `src/api.js` вместо `'ВАШ_КЛЮЧ'` (для учебной работы допустимо, но не выкладывайте такой ключ в открытый репозиторий).

## Что сделано

- Поле ввода и кнопка «Найти» (поиск также по Enter).
- Состояния `query`, `movies`, `status` (`idle` / `loading` / `error` / `success`), `error`.
- Повторный запрос во время загрузки заблокирован (кнопка `disabled` + проверка в `fetchMovies`).
- «Ничего не найдено» определяется по полю `Error` в ответе OMDb; остальные ошибки (неверный ключ, слишком много результатов, нет сети) выводятся как ошибка.
- Пустой запрос, отсутствие постера (`Poster === 'N/A'`) и битая ссылка на постер обрабатываются (заглушка через Data URI).
- Список рендерится через `.map` с `key={movie.imdbID}`; компоненты `App` и `MovieCard`.
- **Шаг 7:** автопоиск при вводе с `useEffect` + debounce 500 мс (включается галочкой), таймер очищается.
- **Доп. задания:** описание фильма (`?i=imdbID`) со спиннером в карточке и кэшем; пагинация (`page`); фильтр «Год от/до»; история последних 5 запросов в `localStorage`.

## Если не работает

| Что видно | Причина и решение |
|---|---|
| Белая пустая страница | Открыли `index.html` двойным щелчком. Проект нужно запускать через `npm run dev` и открывать адрес `http://localhost:5173`. |
| `'vite' не является внутренней или внешней командой` | Не выполнен `npm install` в папке `Lab6_movie-search`. |
| «не задан API-ключ OMDb» | Нет файла `.env`, или Windows сохранила его как `.env.txt` (включите в Проводнике «Расширения имён файлов» и уберите `.txt`), или сервер не перезапущен после создания `.env` (Ctrl+C, затем снова `npm run dev`). |
| «неверный или ещё не активированный API-ключ» | Ключ не активирован: в письме от OMDb есть ссылка активации, по ней нужно перейти. Также проверьте, что ключ скопирован без пробелов и кавычек. |
| «исчерпан дневной лимит запросов» | Бесплатный ключ даёт 1000 запросов в сутки. Каждый поиск — это 1 запрос + до 10 запросов за описаниями фильмов, а автопоиск при вводе расходует их ещё быстрее. Подождите сутки или получите ещё один ключ. |
| «слишком много результатов» | Запрос слишком короткий (например, «a») — введите название подлиннее. |
| «Нет соединения с сервером» | Нет интернета, или сайт omdbapi.com блокируется сетью — попробуйте другую сеть / VPN. |
